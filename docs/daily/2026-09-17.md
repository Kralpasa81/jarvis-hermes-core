# Daily Jarvis/Hermes Lab Note - 2026-09-17

## Kısa Hedef
Hermes Agent'ın cron job yeteneklerini kullanarak otomatik günlük GitHub commit oluşturma işlevselliğini doğrulamak.

## Güvenli Mimari Notu
Gizli anahtarlar veya hassas veriler asla doğrudan kod veya public repo içinde saklanmamalıdır. Çevre değişkenleri veya güvenli bir secrets yönetim sistemi kullanılmalıdır. GitHub Actions secret'ları bu tür durumlar için uygun bir yöntemdir.

## Küçük Yapılabilir Görev
`docs/daily/` dizininde günlük notların düzgün bir şekilde oluşturulduğunu ve `main` branch'e push edildiğini kontrol eden bir test komut dosyası eklemek.

## Gelecekteki Modül Fikri
Bir "Stok Takip Modülü": yerel bir kafenin stok bilgilerini (örn. kahve çekirdekleri, süt) izleyen, düşük stok uyarıları gönderen ve yeniden sipariş için önerilerde bulunan basit bir Hermes modülü.

## Güvenlik/Secret Hatırlatması
Tüm API anahtarları ve kimlik bilgileri `.env` dosyalarında veya Hermes'in güvenli bellek sisteminde saklanmalıdır. Asla bu bilgileri public repolara commit etmeyin.
