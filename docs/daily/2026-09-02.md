# Jarvis-Hermes Lab Note — 2026-09-02

## Bugünün Kısa Hedefi
Session ve event log verilerini insanın okuyabileceği zaman çizelgesi formatına dönüştüren küçük bir yardımcı araç (`session_timeline_formatter.py`) eklenmesi. Amacı: debug/log incelemesini hızlandırmak, ham JSON event akışını net şekilde görselleştirmek.

## Mimari Notu (Güvenli)
Hermes içindeki bileşenler arasında geçen eventlar, çoğunlukla `{timestamp, module, event_type, payload}` yapısındaki düz sözlüklerdir. Bu yapı normalize edilmeden log dosyasına yazıldığında çok sayıda event içinde kaybolmak kolaydır. Basit bir formatter pipeline'ı — sırala → filtrele → renklendir → say — log okunabilirliğini anlamlı biçimde artırır.

## Küçük Yapılabilir Görev
- `session_timeline_formatter.py` ekle ve `examples/` içine yerleştir.
- Formatter'ı `docs/architecture.md` içindeki "Yardımcı Araçlar / Helper Utilities" listesine ekle.
- README'deki examples bölümünü güncelle.

## Gelecekteki Modül Fikri
**Diff-aware log comparator**: iki farklı session'ın event akışını karşılaştırarak hangisinde hangi modülün fazla ya da eksik çalıştığını gösterir. Regresyon tespiti için işe yarar; token/API çağrısı gerektirmez, sadece event log dosyalarına ihtiyaç duyar.

## Güvenlik / Secret Hatırlatması
- Log formatterlar çıktıya **asla** gerçek API key, token fragment veya credential stringi içermemeli.
- Payload alanları log'a yazılmadan önce `public_payload_redactor.py` benzeri bir filtreden geçirilmeli.
- `session_timeline_formatter.py` mock data ile test edilir; gerçek session dosyası repo'ya commit edilmez.
