## Teknik Detay: Regex-Free Parsing Alternatifleri

### 1. Python argparse (Built-in)
```python
import argparse

parser = argparse.ArgumentParser(description='Jarvis CLI')
parser.add_argument('--mode', choices=['dev', 'prod'], default='dev')
parser.add_argument('--config', type=str, required=False)
args = parser.parse_args()

if args.mode == 'prod':
    print(f"Production mode, config: {args.config}")
else:
    print(f"Development mode, config: {args.config}")
```

### 2. Manuel Basit Parsing (Küçük projeler için)
```python
import sys

def parse_args():
    args = {}
    for item in sys.argv[1:]:
        if item.startswith('--'):
            key = item[2:]
            args[key] = True
        elif '=' in item:
            key, val = item.split('=', 1)
            args[key] = val
    return args

if __name__ == "__main__":
    config = parse_args()
    print(f"Parsed config: {config}")
```

### 3. Click (External library)
```python
import click

@click.command()
@click.option('--mode', type=click.Choice(['dev', 'prod']), default='dev')
@click.option('--config', type=str, required=False)

def main(mode, config):
    if mode == 'prod':
        click.echo(f"Production mode, config: {config}")
    else:
        click.echo(f"Development mode, config: {config}")

if __name__ == "__main__":
    main()
```
