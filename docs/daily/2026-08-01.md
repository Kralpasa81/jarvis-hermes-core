# Jarvis/Hermes Lab Note - 2026-08-01

## Bugünün Kısa Hedefi
Otomatik günlük repo güncellemeleri için cron işi altyapısını test etmek ve stabilize etmek.

## Güvenli Mimari Notu
Gizli anahtarların ve API token'larının doğrudan kod depolarında saklanmaması, bunun yerine çevresel değişkenler veya güvenli sır yönetim sistemleri (örneğin, HashiCorp Vault, AWS Secrets Manager) aracılığıyla enjekte edilmesi gerektiğini tekrar hatırlatalım.

## Küçük Yapılabilir Görev
`docs/daily/` dizinindeki günlük notların oluşturulma sürecini otomatikleştiren bir GitHub Actions iş akışı taslağı oluşturulabilir.

## Gelecekteki Modül Fikri
Hermes için basit bir "Durum Raporlayıcı" modülü geliştirmek. Bu modül, belirli aralıklarla sistem durumu hakkında bilgi toplayıp özetleyebilir ve belirlenen bir kanala (örneğin, Slack, Discord) gönderebilir.

## Güvenlik/Gizli Hatırlatma
Yerel geliştirme ortamlarında dahi, API anahtarlarını ve diğer hassas bilgileri `.env` dosyaları gibi `.gitignore` edilmiş dosyalarda tutun ve asla bunları versiyon kontrolüne dahil etmeyin. Public repolar için bu kurala uymak kritik öneme sahiptir.
