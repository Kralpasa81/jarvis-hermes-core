# Daily Lab Notes

Bu dizin, Hermes ajanı tarafından otomatik olarak oluşturulan günlük laboratuvar notlarını içerir. Her not, o günkü küçük bir geliştirme hedefini, mimari gözlemleri, yapılabilir görevleri, gelecekteki modül fikirlerini ve güvenlik hatırlatmalarını barındırır.

## Not Ekleme

Günlük notlar `YYYY-MM-DD.md` formatında eklenmelidir. Örneğin:

```markdown
# Jarvis/Hermes Daily Lab Note - YYYY-MM-DD

## Bugünün Kısa Hedefi
[Kısa hedef]

## Güvenli Mimari Notu
[Güvenli mimari gözlemleri]

## Küçük Yapılabilir Görev
[Yapılabilir küçük görev]

## Gelecekteki Modül Fikri
[Gelecekteki modül veya özellik fikri]

## Güvenlik/Secret Hatırlatması
[Güvenlik veya secret yönetimi hatırlatması]
```

Bu notlar, projenin günlük ilerlemesini ve düşüncelerini belgelemek için kullanılır.
